# Birthday_Wishes_Collector
A lightweight, single-file web application designed for teams to collect, manage, and submit birthday wishes directly to a Google Form backend without requiring authentication or complex APIs.   

✨ Features
Simple Team Login: Authenticates users against an internal template roster (e.g., Member A, Member B).   
Upcoming Birthday Countdown: Dynamically calculates and displays the next team member's upcoming birthday countdown and calendar date. 
CORS-Free Submission: Submits data securely to a Google Form backend using a hidden iframe trick.   
Interactive Navigation: Cycle through other group members using the "Next ➡" control.   
Zero Dependencies: Pure vanilla JavaScript, CSS, and HTML template.
